一句话总结：我们用 10 亿个偶数做了一次"普查"，发现哥德巴赫素数对的数量波动，比扔硬币的波动还小——这是个意外的发现。

什么是哥德巴赫猜想？ 每个大于 2 的偶数都可以写成两个素数之和。比如 10 = 3 + 7 = 5 + 5，有 2 种写法。偶数越大，写法越多。

我们发现了什么？ 写法的数量虽然在增长，但它围绕平均值的波动幅度，比随机过程（泊松分布）的波动还要小一半左右。就好像有人在暗中"调节"素数对的分布，不让它太密也不让它太疏。

这意味着什么？ 素数之间可能存在某种微妙的"排斥性"关联，使得哥德巴赫分拆数比预期的更稳定。这种关联的来源目前还不清楚——这正是最令人兴奋的地方。

核心结论

三条互相独立的证据链共同表明：哥德巴赫计数 g(N) 的涨落始终是亚泊松的。

  1. 零参数漂移律：K(N) = g(N)·ln²N / (N·S(N)) 的均值可以从 Hardy–Littlewood 奇异级数精确定出，零拟合参数，在 17 个尺度（5×10⁵ → 10⁹）上与实测偏差从 0.42% 单调收窄到 0.008%。
  2. 漂移假象：宽窗口 [N/2, N] 下 κ > 1 的"超泊松"现象，完全来自 K(N) 的确定性 1/lnN 漂移被计入方差。漂移占比从 5×10⁵ 的 8.4% 单调增长到 10⁹ 的 87.5%。
  3. 模型无关验证：10⁹ 尺度的窄窗口 [0.9N, N] 实验直接给出 κ_naive = 0.620 < 1，不需要任何漂移修正假设就证明了亚泊松。

剥离漂移后，真实噪声 Fano 因子 κ_noise ∈ [0.50, 0.55]，对应 σ(g) / ⟨g⟩ ≈ 0.54 / √⟨g⟩。

0　相关工作

哥德巴赫问题已有近 280 年的历史，相关文献浩如烟海。这里不做全面综述，仅梳理与本研究直接相关的几条脉络，说明我们的工作在已有图景中的位置。

0.1　Hardy–Littlewood 圆法

1923 年，Hardy 和 Littlewood 在其经典论文 "Some problems of 'Partitio numerorum'; III: On the expression of a number as a sum of primes" 中创立了圆法，并提出了哥德巴赫分拆数的渐近公式：

r₂(N) ~ 2C₂ · ∏_{p|N, p>2} (p−1)/(p−2) · N / ln²N

其中 C₂ = ∏_{p>2} (1 − 1/(p−1)²) ≈ 0.66016 为孪生素数常数，乘积部分即奇异级数 S(N)。

这一公式是本研究的理论出发点。我们定义的归一化计数 K(N) = g(N)·ln²N / (N·S(N))，正是将 g(N) 除以 H-L 主项后得到的"残差系数"。如果 H-L 猜想成立，K(N) 应当趋向于一个常数（即 2C₂ = 1.320... 当 N→∞ 时——但请注意我们的 K 定义中已经除以了 S(N)，所以极限值应为常数而非发散）。

注：不同文献中 g(N) 的定义略有差异（是否计顺序、是否允许 p=q），导致 K(N) 的极限常数也不同。本研究采用不计顺序的定义，且 1 不视为素数。

0.2　Kan 1992：哥德巴赫方差

1992 年，阚家海（Jia-Hai Kan）在 "On the variance of the Goldbach function" 一文中，利用筛法和圆法的结合，研究了哥德巴赫函数的方差。其核心结果包括：

  • 在一定的假设条件下（如广义黎曼猜想的某种形式），Var(g(N)) 的主阶可以被估计。
  • 方差的主导项来自奇异级数 S(N) 的分布——不同 N 对应的 S(N) 值的波动是 g(N) 涨落的主要来源。
  • 结果与概率模型的预期一致：如果把素数看作独立随机事件，g(N) 的方差应当大致与其均值同阶。

Kan 的工作是我们已知的文献中最直接相关的。本研究中的"耦合刚性 β(y)"概念——即 K 的涨落由 S(N) 驱动的程度——与 Kan 的分析思路一脉相承。我们的贡献在于：

  1. 精确的数值验证：在 10⁹ 尺度上系统测量了 κ 和 Fano 因子，给出了亚泊松性质的强数值证据。
  2. 漂移假象的发现：指出了宽窗口下 κ_naive > 1 的"超泊松"现象来自均值漂移，并非真实涨落。
  3. 模型无关验证方法：提出窄窗口实验和 ANOVA 两种无需依赖漂移律的验证方法。

0.3　素数分布的涨落

哥德巴赫问题的涨落不是孤立的，它与素数分布本身的涨落问题密切相关。这一领域的经典工作包括：

  • Cramér 模型（1936）：将素数建模为独立随机事件，n 为素数的概率为 1/log n。在这个模型中，区间 [x, x+y] 内素数个数近似泊松分布。许多关于素数间隙、素数计数涨落的启发式论证都基于此模型。
  • Montgomery 对关联猜想（1973）：Montgomery 提出了黎曼 ζ 函数零点间距的对关联猜想，它等价于素数在短区间内的分布具有特定的排斥性关联——素数之间"相互避让"。这一猜想预言了素数计数涨落会偏离泊松分布。
  • Goldston–Montgomery–Özlük–Snyder（1999）：在黎曼假设下证明了短区间素数计数方差的渐近公式，与 Montgomery 对关联猜想一致。
  • Odlyzko 等人的数值验证：大量数值计算验证了零点间距和素数涨落的统计性质，为上述猜想提供了有力的数值支持。

本研究发现的亚泊松性质，可以看作哥德巴赫框架下的类似现象——素数对之间也存在某种"排斥关联"，使得涨落被抑制。两者之间是否存在直接的定量联系，是一个值得进一步研究的问题。

0.4　哥德巴赫问题的数值研究

对哥德巴赫猜想的数值验证有着悠久的历史，从手动计算到超级计算机，验证范围不断扩大：

  • 到 19 世纪末，验证到 10,000 量级
  • 1938 年，Pipping 验证到 100,000
  • 1964 年，Stein & Stein 验证到 10⁸
  • 2000 年，Richstein 验证到 4×10¹⁴
  • 2008 年，Oliveira e Silva 等人验证到 1.2×10¹⁸

然而，这些研究主要关注的是"哥德巴赫猜想是否成立"（即 g(N) ≥ 1），而非 g(N) 的统计性质。对 g(N) 涨落的系统性数值研究相对较少。

我们知道的与涨落直接相关的数值工作包括：

  • 对 g(N) 上界和下界的经验估计（如"哥德巴赫彗星"图的绘制）
  • 对 g(N) 分布形状的观察（如多峰结构，来自奇异级数的不同因子组合）
  • 对 g(N) 极值序列的追踪（OEIS A002375 等）

但据我们所知，系统测量 g(N) 的 Fano 因子并指出其亚泊松性质的工作，此前尚未有明确报道。这可能部分是因为漂移假象的存在——在宽窗口下 κ_naive > 1，容易让人误以为涨落是超泊松的，从而忽略了进一步探究的必要。

0.5　我们的定位

本研究的贡献

在哥德巴赫问题的庞大研究图景中，本工作属于数值实验的范畴，主要贡献在于：

  1. 发现并澄清了"漂移假象"——这是一个简单但容易被忽视的方法论问题，可能误导了对涨落性质的直觉判断。
  2. 提供了亚泊松涨落的强数值证据——通过漂移修正、ANOVA 上界和窄窗口模型无关验证三条独立路径，一致指向 κ_noise ≈ 0.54。
  3. 提出了一系列精确表述的猜想和开放问题——希望能吸引解析数论研究者的注意，将这个方向往前推进。
  4. 建立了可扩展的计算框架——Goldwing Core + Python/FFT 双路验证，可以高效地推广到更大尺度和更多统计量。

1　背景与问题

1.1　哥德巴赫计数与 K(N)

设 g(N) 为偶数 N 的哥德巴赫分拆数（不计顺序的素数对 p + q = N 的个数）。Hardy–Littlewood 圆法预言

g(N) ~ S(N) · N / ln²N

其中 S(N) = 2C₂ · ∏_{p|N, p>2} (p−1)/(p−2) 是奇异级数，C₂ = ∏_{p>2} (1 − 1/(p−1)²) ≈ 0.66016 是孪生素数常数。

定义归一化计数 K(N)：

K(N) = g(N) · ln²N / (N · S(N))

若 H-L 猜想成立，K(N) → C₂ = 0.66016...。但我们更关心的是 K(N) 的涨落——它围绕均值的波动幅度有多大？

1.2　涨落的度量：κ 和 Fano 因子

对于独立随机事件，计数服从泊松分布，其变异系数 CV = σ/μ = 1/√μ。定义 κ 为实际 CV 与泊松 CV 的比值：

κ = CV_K / CV_{K, poisson}  =  σ(K)/⟨K⟩  /  √(⟨Var_poisson(K)⟩)/⟨K⟩

等价地，κ² 就是 g(N) 的 Fano 因子 F = Var(g)/⟨g⟩。κ = 1 对应泊松水平，κ < 1 为亚泊松（涨落被抑制），κ > 1 为超泊松（涨落被放大）。

一个令人困惑的现象

在宽窗口 [N/2, N] 下直接测量 κ_naive = CV_K / CV_poisson，发现它从 5×10⁵ 的 0.52 单调上升，在 N* ≈ 2×10⁸ 处穿越 1，到 10⁹ 时达到 1.53。如果这是真实物理，就意味着涨落在大尺度从"抑制"翻转为"放大"——需要全新的机制解释。

2　零参数漂移律

在深入讨论涨落之前，我们先确立一个关键事实：K(N) 的均值不是常数，而是随 N 缓慢漂移，其形式可以从 H-L 奇异级数精确导出，不含任何拟合参数。

2.1　推导

考虑窗口 [N/2, N] 内的平均 K 值。K(M) = g(M)·ln²M/(M·S(M)) 的期望值来自对所有素数对的平均。利用 H-L 奇异级数的精确形式，可以将 E[K(M)] 写成积分：

K(M) = 2C₂ · (ln²M / M) · ∫2M/2 dx / (ln x · ln(M−x))

这个积分没有初等闭式，但可以用 Gauss–Legendre 数值积分以机精度计算。关键是：它完全由已知常数决定，没有可调参数。

2.2　17 尺度验证

我们在 17 个尺度（5×10⁵ 到 10⁹，含 C++ 和 Python/FFT 两条独立计算路径）上验证了这个公式。结果如下：

3　漂移假象：κ > 1 的来源

3.1　方差的分解

既然 K(M) 的均值在窗口内随 M 漂移，那么窗口内的总方差就包含两部分：

Var_total = Var_trend + Var_noise

其中 Var_trend 是均值漂移带来的"假"方差（确定性的），Var_noise 才是真正的随机涨落。对应的变异系数：

CV²_total = CV²_trend + CV²_noise

A5 残差律

进一步分析发现，零参数漂移律的残差 |ΔK| = |⟨K⟩_实测 − ⟨K⟩_理论| 服从精确的幂律：

|ΔK| = 3.418 · N−0.530    (R² = 0.9994)

指数 −0.530 非常接近 −0.5，说明残差本质上是有限 N 的统计涨落效应——漂移律的精度极限由样本量决定。

4　模型无关验证：窄窗口实验

上面的分析依赖一个前提：漂移律是正确的，可以从总方差中减去。虽然漂移律的吻合度很高（0.008%），但严格来说它还是一个"模型"。

有没有不依赖任何模型的方法来确认亚泊松？

4.1　思路：收窄窗口

答案很简单：把窗口收窄。

因为漂移占比来自窗口两端的均值差，窗口越窄，漂移越小。当窗口足够窄时，漂移的贡献可以忽略，此时 κ_naive 就直接等于 κ_noise（或者说就是它的一个很好的上界）。

关键不等式

因为漂移只会增加方差（Var_trend ≥ 0），所以 κ_naive ≥ κ_noise 恒成立。因此只要实测 κ_naive < 1，就无条件证明了 κ_noise < 1——不需要漂移律，不需要 ANOVA，不需要任何拟合假设。

4.2　实验设计

我们在 10⁹ 尺度上做了一个窄窗口实验：窗口取 [0.9N, N] = [9×10⁸, 10⁹]，宽度仅 10%。

  • 有效样本：50,000,001 个偶数
  • 理论预测漂移占比：~16.6%（对比宽窗口的 87.5%）
  • 理论预测 κ_naive：~0.59（κ_noise = 0.54 时）
  • 计算平台：56 核服务器，耗时约 6.2 小时

5　讨论

5.1　三条证据链的一致性

我们有三条独立的路径来估计 κ_noise，它们都指向同一个结论：

方法10⁹ 处 κ_noise是否依赖模型
五区块 ANOVA（模型无关）≤ 0.647（上界）否
窄窗口 10%（模型无关）≤ 0.620（上界）否
零参数漂移律修正≈ 0.540是（漂移律）

两个模型无关的上界都远小于 1，而且漂移律修正后的估计值落在上界之内——三条路径自洽。

5.2　亚泊松的可能来源

为什么哥德巴赫计数的涨落会低于泊松水平？一个直观的理解是：素数不是独立随机变量，它们之间存在排斥性关联（一个数是素数会降低其邻居是素数的概率）。当我们统计素数对时，这种排斥性会导致分拆数的涨落被抑制。

然而，κ ≈ 0.54 这个具体数值意味着什么？Fano 因子 F ≈ 0.29 的来源是什么？目前这还是一个开放问题。Kan (1992) 的工作在奇异级数的平均性质上给出了精确的结果，但方差的统计性质还没有完整的理论刻画。

5.3　方法学意义

这项工作的一个副产品是方法论上的：在研究数论函数的统计性质时，必须小心处理"均值漂移"问题。

当函数 f(N) 随 N 有系统性变化时，窗口内的总方差会被确定性漂移污染，从而误导对涨落强度的判断。对于缓慢变化的函数（如 K(N) ~ O(1/lnN)），这个效应在大尺度尤其严重——漂移占比可以从几个百分点涨到近 90%。

窄窗口方法提供了一个简单而稳健的解决方案：只要窗口足够窄，漂移的贡献就可以被控制在任意小的水平，从而得到模型无关的涨落强度上界。

5.4 耦合刚性视角：β(y) 饱和曲线

换一个角度看 K(N) 的涨落：定义 耦合刚性 β(y) 为 K 的涨落与奇异级数 S 的涨落之比：

β(y) = Var(K(y)) / Var(S(y))

其中 y 是以素数平均间距为单位的窗口宽度（y = 窗口宽度 / ln N）。这个量刻画了 K 的涨落被奇异级数"驱动"的程度：

  • 当 y → 0（极窄窗口）：每个 N 对应的 S(N) 几乎不变，Var(S) → 0，但 K 的涨落还有来自素数分布随机性的部分，因此 β → 0
  • 当 y → ∞（极宽窗口）：K 的涨落完全由 S(N) 的分布决定，β → 1（完全耦合）
图 13：耦合刚性 β(y) 的饱和曲线示意图。小 y 时 β 从零开始上升（弱耦合区），中等 y 时快速增长（过渡区），大 y 时趋近于 1（饱和区）。饱和行为意味着宽窗口下 K 的涨落本质上就是奇异级数的涨落。

耦合刚性视角为我们提供了一个统一框架：宽窗口下 κ_naive > 1 的假象，本质上是因为 β(y) 已经饱和（β ≈ 1），而漂移带来的额外方差又叠加在 S(N) 的涨落之上。窄窗口方法之所以有效，是因为它把窗口缩到了 β(y) 尚未饱和的区域，此时漂移的贡献自然消失。

6　对称素数对最小距离 d(N) 的统计性质

除了 K(N) 的涨落，哥德巴赫问题中另一个值得关注的统计量是 对称素数对最小距离 d(N)：

d(N) = min { k ≥ 1 : N−k 与 N+k 同为素数 }

d(N) 衡量了从 N 出发向两侧同时寻找素数的"难度"——它本质上是一个首次击中时间问题。与 K(N) 不同，d(N) 是一个极端值统计量，其分布应该具有长尾特征。

6.1　d_pair^max 的增长律

我们首先考察 d(N) 在区间 [2, N] 上的纪录最大值 d_pair^max(N) 随 N 的增长。使用 OEIS A129301/A129302 的 69 条官方记录（覆盖 N 从 4 到 2.1×10⁹），结合本项目的独立计算值，得到下图：

图 9：对称素数对最小距离的纪录值 d_pair^max(N) 随 N 的增长（偶 N）。紫色点为 OEIS A129301 官方记录，蓝色点为本项目计算值，红色虚线为 C·(ln N)^p 幂律拟合（p ≈ 3.47）。

拟合结果显示 d_pair^max(N) 可以很好地用对数幂律描述：

d_pair^max(N) ≈ 0.164 · (ln N)3.47    (RMS_log = 0.086)

指数 p ≈ 3.47 落在 3~4 之间，与启发式论证一致：如果对固定 N，d(N) 近似服从几何分布、均值 ~ c·ln²N（由素数密度 1/lnN 的乘积给出），那么在 N 以下取极值时，极值大约增长 lnN 倍，因此总体量级 ~ (lnN)³。实测 p=3.47 比纯 (lnN)³ 稍大，可能来自素数分布中的小尺度关联或有限 N 修正。

6.2　d(N) 的分布形态

为了看清 d(N) 的完整分布，我们在 [9.9M, 10M] 区间内计算了 50,001 个偶数的 d(N) 值：

图 10：10M 尺度附近 d(N) 的分布直方图（50,001 个偶数样本）。分布呈现强烈的右偏（长尾）特征，中位数 93，均值 140.3，最大值 1665。d 值越小频率越高，近似几何分布。

分布的主要特征：

  • 右偏长尾：中位数 93 远小于均值 140.3，偏度为正，符合"首次击中时间"的典型形态。
  • 近似几何衰减：小 d 区域频率快速下降，但尾部衰减慢于指数——这与几何分布的理论预期定性一致。
  • 奇偶交替：由于 N 为偶数，N±k 同奇偶，k 必须为奇数（否则 N±k 均为偶数），因此 d(N) 恒为奇数——分布中所有偶数 d 的计数为零。
与 K(N) 涨落的关系

d(N) 和 K(N) 从两个不同角度刻画哥德巴赫分拆的统计性质：K(N) 描述"有多少个分拆"（计数型统计量），d(N) 描述"最近的分拆有多远"（等待时间型统计量）。两者之间可能通过极值理论联系起来——K(N) 的亚泊松涨落意味着分拆数的波动被抑制，这应该也会体现在 d(N) 的尾部行为中。定量联系有待进一步研究。

7　结论

主要结果
  1. 零参数漂移律：K(N) 的均值可以从 Hardy–Littlewood 奇异级数精确计算，零拟合参数，在 5×10⁵ → 10⁹ 的 17 个尺度上与实测偏差从 0.42% 单调收窄到 0.008%。
  2. 漂移假象：宽窗口下 κ > 1 的"超泊松"现象完全来自均值漂移。漂移占比从 8.4% 增长到 87.5%（10⁹），真实 κ_noise 始终在 0.50–0.55 之间。
  3. 模型无关验证：10⁹ 尺度窄窗口 [0.9N, N] 实验给出 κ_naive = 0.620，无条件证明了亚泊松涨落，不依赖任何漂移修正假设。

下一步工作方向：

  • 更窄窗口（如 5%）的高精度测量，以更精确地确定 κ_noise 的值
  • κ_noise 的缓慢上升（0.50 → 0.55）是真实效应还是有限尺度假象？需要更大尺度或更精细的分析
  • 亚泊松的理论解释：能否从素数分布的已知性质推导出 Fano 因子的量级？
  • d(N) 分布与 K(N) 涨落的定量联系——d(N) 的长尾行为是否也受亚泊松机制影响？

数据与代码：所有计算使用 Goldwing Core（C++）和独立 Python/FFT 实现双路验证。原始数据和分析脚本可应要求提供。
计算资源：1B 尺度宽窗口计算约 28 小时，窄窗口约 6 小时，均在 56 核服务器上完成。

7　开放问题与猜想

基于本研究的数值证据，我们提出以下猜想和开放问题。它们从相对"安全"的渐近表述逐渐过渡到更具推测性的机理问题，供感兴趣的研究者进一步探索。

7.1　猜想：亚泊松涨落

猜想 1（哥德巴赫计数的亚泊松性质）

存在 N₀，使得对所有偶数 N ≥ N₀，

VarN/2 ≤ M ≤ N g(M)  /  ⟨g(M)⟩  <  1

即：当 N 充分大时，哥德巴赫分拆数 g(M) 在窗口 [N/2, N] 内的 Fano 因子严格小于 1，其涨落为亚泊松型。

数值证据：在 N = 10⁹ 处，漂移修正后的 κ_noise ≈ 0.540，对应 Fano 因子 F ≈ 0.292；模型无关的窄窗口实验给出 κ_naive = 0.620（上界）。在所有 17 个测量尺度（5×10⁵ 到 10⁹）上，κ_noise 始终落在 [0.50, 0.55] 区间内，从未接近过 1。

强度评级：⭐⭐⭐⭐（强数值证据）

7.2　猜想：κ 的极限值

猜想 2（κ_noise 趋向一个常数）

存在常数 κ_∞ ≈ 0.54 ± 0.02，使得

limN→∞ κ_noise(N) = κ_∞

其中 κ_noise(N) 是窗口 [N/2, N] 内剥离漂移后的归一化涨落强度。

数值证据：从 5×10⁵ 到 10⁹，κ_noise 从 0.50 缓慢增长到 0.54，增长速率持续减慢，呈现出向某个极限值收敛的迹象。但 3.3 个数量级的尺度范围仍不足以做出决定性判断——如果收敛速度是 O(1/log N)，那么到 10⁹ 处可能只完成了收敛的一部分。

相关的子问题：

  • κ_∞ 是一个普适常数吗？它是否可以从已知的数论常数（如 C₂、孪生质数常数等）构造出来？
  • 收敛速度是多少？是 O(1/log N)、O(1/√log N)，还是更慢？
  • κ_noise(N) 是单调递增的吗？我们的数据显示整体递增，但局部有小幅波动。

强度评级：⭐⭐⭐（中等证据，需更大尺度验证）

7.3　猜想：零参数漂移律的渐近展开

猜想 3（K(N) 均值的渐近展开）

K(N) = g(N)·ln²N / (N·S(N)) 的均值有如下渐近展开：

⟨K(N)⟩ = 2C₂ · Φ(1/ln N) + a₁/ln N + a₂/ln²N + O(1/ln³N)

其中 Φ(u) 是某个可从奇异级数积分确定的函数，a₁, a₂, … 是可计算的常数。

数值证据：零参数主项（2C₂·Φ）与实测的偏差从 5×10⁵ 处的 0.42% 单调收窄到 10⁹ 处的 0.008%，收敛速度符合 1/ln N 量级。残差 |ΔK| = 3.418·N−0.530 的幂律行为（A5 律）暗示展开的下一阶可能具有统计涨落的性质，而非纯确定性修正。

开放问题：

  • 能否从 Hardy-Littlewood 圆法或筛法出发，严格推导出下一阶修正项 a₁/ln N？
  • 残差的幂律收敛（指数 ≈ −0.53）有解析解释吗？它接近 −1/2 是否暗示了某种中心极限定理式的行为？

强度评级：⭐⭐⭐⭐（主项强证据，高阶项待探索）

7.4　猜想：d(N) 增长律

猜想 4（对称素数对最小距离的增长）

设 d(N) = min{ d ≥ 1 : N−d 和 N+d 均为素数 } 为偶数 N 的对称素数对最小距离。则存在常数 C, γ > 0，使得

d_pair^max(N) ~ C · (log N)^γ

其中 d_pair^max(N) = max_{M ≤ N} d(M) 是到 N 为止的最大 d(M) 值。我们的数值拟合给出 γ ≈ 3.47。

数值证据：从 69 条 OEIS 纪录值加上我们在大尺度上的计算点，d_pair^max(N) 在双对数坐标下呈现良好的线性关系，R² > 0.99。指数 3.47 落在基于概率启发式推导的预期范围（3 ~ 4）内。

相关问题：

  • γ 的精确值是什么？它等于 3 + ε 还是某个已知常数？
  • d(N) 的分布是否收敛到某个标准形式（如 Gumbel 分布、几何分布的某种变形）？
  • d(N) 与 K(N) 之间有定量关系吗？比如 K 值偏低的偶数是否倾向于有更大的 d(N)？

强度评级：⭐⭐⭐（良好证据，但纪录值数据点有限）

7.5　问题：亚泊松的机理

这是本研究中最深层也最具推测性的问题：为什么涨落是亚泊松的？

在物理和概率中，亚泊松现象通常来自某种"排斥效应"——粒子之间相互避让，使得它们的分布比随机更均匀。在哥德巴赫问题中，可能的机理包括：

可能的机理方向
  1. 素数分布的刚性：素数本身的分布就具有某种规律性（如素数定理给出的密度、Montgomery 对关联猜想等），这种规律性通过 p + q = N 的约束传递到 g(N) 上，抑制了涨落。
  2. 奇异级数的平均效应：K(N) 的涨落主要由 S(N) 驱动（耦合刚性 β → 1），但 S(N) 的分布本身具有有限的 CV（≈ 0.39）。经过 g(N) 统计平均的"稀释"后，最终的涨落被进一步压低。
  3. 筛结构的关联：每个素数模 m 对 g(N) 施加了周期性约束（类似于筛法中的同余条件），这些约束之间的相互作用可能产生反关联，从而降低方差。
  4. 中心极限定理的偏离：如果把 g(N) 看作许多独立或弱相关贡献的和，那么中心极限定理给出泊松/正态分布。但如果这些贡献之间存在负关联，结果就会是亚泊松的。

我们倾向于认为第 1 和第 2 条的组合是主要原因——素数本身的分布规律性是"原料"，奇异级数的耦合与平均是"加工过程"，最终产出的是 Fano 因子约 0.3 的亚泊松涨落。但这只是一个工作假设，距离严格论证还很远。

具体的研究方向：

  • 在 Cramér 型随机素数模型中计算 g(N) 的方差，看是否也给出亚泊松结果——如果是，说明亚泊松可能只需要素数的"独立性+密度"，不需要更深刻的结构。
  • 计算 g(N) 分布的高阶矩（偏度、峰度），看它们是否偏离泊松分布，以及偏离的方向。
  • 研究不同模 m 下 g(N) 的条件分布，看各同余类之间的涨落是否存在关联。

强度评级：⭐⭐（推测性，需要更多证据）

7.6　方法论问题

除了数论本身的问题，本研究还提出了一些方法论层面的问题：

  • 窄窗口验证方法：我们提出的"窗口越窄，κ_naive 越接近 κ_noise，且始终为上界"的思路，是否可以推广到其他具有漂移的计数问题？这是否是一种通用的"模型无关"检验涨落性质的方法？
  • 五区块 ANOVA：用组内方差作为 κ_noise 上界的方法，其精度如何随区块数变化？最优区块数是多少？
  • 漂移律的零参数特性：在什么条件下，一个计数问题的均值漂移可以从零参数的"主项公式"精确算出？哥德巴赫问题的这种性质是特例还是通例？

7.7　小结

我们的信念

哥德巴赫计数的涨落问题，可能比人们之前认为的更丰富、更深刻。它不仅仅是"g(N) 大约有多大"的问题，还涉及：

  • 涨落的强度（亚泊松还是超泊松？）
  • 涨落的结构（高斯还是偏斜？长尾还是短尾？）
  • 涨落的来源（奇异级数驱动？素数分布的刚性？）
  • 涨落的尺度演化（随 N 增大如何变化？趋向什么极限？）

我们希望这份数值研究能够吸引更多的注意力，无论是解析的还是数值的，共同把这个方向往前推进一小步。

D.2　C++ Goldwing Core 算法

主计算路径使用 C++ 实现，核心算法流程如下：

  1. 埃拉托斯特尼筛：生成 [2, N] 范围内的素数表，使用位压缩存储（1 bit 一个奇数），内存占用 N/16 字节。对于 N = 10⁹，素数表约 60 MB。
  2. 逐偶数扫描：对每个偶数 M 从 4 到 N：
    • 利用素数表从小到大尝试 p，检查 M−p 是否也是素数
    • 累计分拆数 g(M)
    • 同时记录 K(M) = g(M)·ln²M / (M·S(M)) 的运行统计
  3. 奇异级数 S(M) 的增量更新：由于 M 从一个偶数走到下一个偶数，S(M) = 2C₂·∏_{p|M, p>2} (p−1)/(p−2) 的变化只涉及 M 的素因子。利用 M 增 2 时素因子的变化模式，可以高效更新 S(M)，避免每次重新分解。
  4. 窗口统计：维护一个滑动窗口内的 K 值列表，在指定 N 处输出窗口统计量（均值、方差、极值等）。
  5. 多线程并行：使用 OpenMP 将大区间划分为多个子区间，每个线程独立计算一个子区间内的 g(M) 和 K(M)，最后合并统计结果。

D.3　Python/FFT 验证路径

为了独立验证 C++ 计算的正确性，我们使用 Python + NumPy 实现了一条完全不同的计算路径，基于卷积方法：

  • 素数指示向量：构造长度为 N 的 0-1 向量 P，其中 P[i] = 1 当且仅当 i 是素数。
  • 自卷积：g(N) = (P * P)[N] / 2（不计顺序），即素数指示向量的自卷积在 N 处的值的一半。
  • FFT 加速：使用 FFT（Fast Fourier Transform）在 O(N log N) 时间内完成卷积。

这条路径的优势是算法简洁（卷积定义直截了当），不易引入逻辑错误；缺点是内存和时间复杂度较高，仅适用于较小的尺度（通常 N ≤ 2×10⁷）。

D.4　双路验证

我们在所有 Python/FFT 路径可达的尺度上（5×10⁵ 到 2×10⁷），将 C++ 结果与 FFT 结果进行了逐点对比：

  • 均值 K：两条路径的差异 ≤ 10⁻⁶（远小于涨落幅度）
  • g(N) 总数：完全一致（整数级精确匹配）
  • 统计量：方差、偏度等统计量的相对差异 ≤ 0.1%

对于 Python 路径无法覆盖的大尺度（5×10⁷ 到 10⁹），我们依赖 C++ 核心的内部一致性检验：

  • 不同线程数下结果一致
  • 不同区间划分方式下结果一致
  • 正反向扫描结果一致

D.5　统计方法

D.5.1　宽窗口测量

对每个测量点 N，取窗口 [N/2, N] 内所有偶数的 K(M) 值，计算样本均值和样本方差：

⟨K⟩ = (1/n) Σ K(M_i),     Var(K) = (1/(n−1)) Σ (K(M_i) − ⟨K⟩)²

其中 n = N/4 为窗口内偶数个数。κ_naive = CV_K / CV_poisson，其中 CV_poisson = 1/√⟨g⟩ 为泊松分布的变异系数。

D.5.2　漂移修正

利用零参数漂移律 K_theory(N)，从总方差中减去漂移贡献：

Var_noise = Var_total − Var_trend,     Var_trend = (1/n) Σ (K_theory(M_i) − ⟨K_theory⟩)²

κ_noise = √Var_noise / (⟨K⟩ · CV_poisson)。

D.5.3　五区块 ANOVA

将窗口均匀分为 5 个区块，计算组间方差和组内方差。组内方差给出 Var_noise 的一个上界（因为区块内仍可能有微量漂移）。

D.5.4　窄窗口实验

使用窗口 [0.9N, N]（宽度为 N 的 10%），直接测量 κ_naive。由于漂移占比在窄窗口中大幅降低（~15% vs ~87.5%），此时 κ_naive 已经接近 κ_noise，且始终为其上界。

D.6　误差估计

本研究的误差来源包括：

误差来源量级说明
统计采样误差≤ 0.5%样本量充足（百万级偶数），统计误差可忽略
漂移律系统偏差0.008% @ 10⁹零参数理论与实测的偏差，随 N 增大单调减小
有限窗口效应~1%窄窗口下样本量减少，统计误差略有增大
数值精度≤ 10⁻⁶64 位双精度浮点运算，精度充足

综合来看，κ_noise 的测量误差估计在 ±0.02 以内，足以支撑"亚泊松"（κ < 1）的定性结论，也足以支持 κ ≈ 0.54 的定量估计。
