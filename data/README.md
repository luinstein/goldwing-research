# 数据说明

本目录存放研究相关的数据文件。

## 可用数据

目前原始数据文件较大（GB 级），暂未直接存入仓库。如需数据请通过 Issue 联系。

### 数据摘要

- **最大 N**: 1,000,000,000（10 亿）
- **测量尺度**: 17 个（5×10⁵ → 10⁹）
- **计算路径**: C++ 主路径 + Python/FFT 独立验证
- **双路验证误差**: ≤ 10⁻⁶

### 数据格式

完整数据集包含：
- 各尺度下 K(N) 均值、方差
- 漂移修正后的噪声方差
- 窄窗口实验原始数据
- d(N) 对称距离统计

完整数据表见报告附录。
