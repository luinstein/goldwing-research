## 🚀 第一篇发布：01 漂移假象

### 步骤 1：进入创作中心

1. 打开 https://www.zhihu.com 并登录宝叔观察账号
2. 右上角点击头像 → 选择「创作中心」
3. 左侧菜单找到「文章」→ 点击「写文章」

### 步骤 2：填写标题

1. 在标题栏输入：

```
【金翼计划】为什么哥德巴赫分拆数的"超泊松涨落"是假的
```

2. 确认标题末尾没有多余空格

### 步骤 3：复制正文

1. 打开文件 `01_漂移假象_发布版.md`
2. 全选内容：按 `Ctrl + A`
3. 复制：按 `Ctrl + C`

### 步骤 4：粘贴到知乎编辑器

1. 点击知乎正文编辑区
2. 全选删除原有内容（如果有的话）：按 `Ctrl + A` → `Delete`
3. 粘贴：按 `Ctrl + V`
4. 等待 2-3 秒，让知乎完成 Markdown 解析

### 步骤 5：检查格式（重要！）

粘贴后，**从上到下滚动一遍**，重点检查：

#### ✅ 5.1 标题层级
- 主标题 H1：应该没有（标题栏单独填了）
- 章节标题 H2（`##`）：应该是大号粗体字
- 小节标题 H3（`###`）：应该是中号粗体字

> 如果 H2/H3 看起来不对（比如只是加粗文字），选中那行 → 点击工具栏的「标题」按钮 → 选择二级/三级标题。

#### ✅ 5.2 引用块
- 文首的**口径修正说明**应该在灰色引用块里
- 文中的 `>` 引用内容也应该有灰色背景

> 如果引用块没出来，选中那段 → 点击工具栏的「引用」按钮（引号图标）。

#### ✅ 5.3 公式检查（最容易出问题）

逐一看每个公式：

**行内公式**（`$...$`）：
- 应该直接渲染成数学符号
- 如果显示成 `$K(N)$` 原文字，说明没被识别
  - 解决：选中公式文字 → 点击工具栏「公式」→ 选择「行内公式」→ 重新输入或粘贴 LaTeX 代码

**块级公式**（`$$...$$`）：
- 应该居中显示，有独立一行
- 如果显示成 `$$ K(N) = ... $$` 原文字，说明知乎没识别
  - 解决：选中整行公式 → 点击工具栏「公式」→ 选择「块级公式」→ 粘贴 LaTeX 代码

> 💡 **小技巧**：如果公式很多，建议重点检查这几个关键公式就行：
> - K(N) 定义公式
> - 漂移律公式（2·Φ(1/ln N)）
> - 文末的公式（如果有）
> 其他公式即使有点小问题，不影响理解。

#### ✅ 5.4 表格检查
- 数据表格应该正常显示成行和列
- 数值对不对？抽查几个：⟨K⟩ 应该都在 1.1 左右
- 表头应该加粗或有底色

> 如果表格没渲染好，删掉重新粘贴一次试试。知乎对 Markdown 表格支持还可以。

#### ✅ 5.5 链接检查
- 点击文中的链接（如「完整版报告」），确认能打开正确的页面
- 报告链接应该是：`https://luinstein.github.io/goldwing-research/paper/goldwing_v1.7_subpoisson.html`
- GitHub 链接应该是：`https://github.com/luinstein/goldwing-research`

### 步骤 6：添加首图（可选但推荐）

1. 光标移到文章最开头（标题下面第一行）
2. 点击工具栏「图片」按钮 → 「上传图片」
3. 选择 `correction_banner.jpg`
4. 等待上传完成
5. 图片上传后，可以加个图片说明：`K(N) 口径修正说明`

> 💡 如果你觉得文首已经有文字版修正说明了，不需要再放图，也可以不加。

### 步骤 7：添加文末金翼计划标识

发布版里已经有文末标识了，确认一下最后有：
- 「关于金翼计划」的标题
- 研究报告链接
- GitHub 链接
- 作者署名

> 如果缺失，从文末复制补上。

### 步骤 8：设置话题 / 专栏

1. 在编辑器右侧（或底部）找到「话题」设置
2. 添加相关话题（建议 3-5 个）：
   - 哥德巴赫猜想
   - 数论
   - 数学
   - 素数
   - 理论物理（如果内容有涉及）

3. 「收录专栏」：如果宝叔观察有专栏，选一个合适的专栏收录
   - 如果没有专栏，可以不选
   - 或者创建一个叫「金翼计划」的专栏

### 步骤 9：预览

1. 点击「预览」按钮
2. 用读者视角从头看一遍
3. 重点看：
   - 首屏效果（标题 + 首图 + 开头几段）
   - 公式是否清晰可读
   - 表格是否对齐
   - 文末标识是否完整

### 步骤 10：发布

1. 确认一切没问题
2. 点击「发布」按钮
3. 可能会弹出版本声明/原创声明，按要求勾选
4. 发布成功后，复制链接保存

## 🔧 常见问题与解决办法

### Q1：公式显示成源代码（$...$ 原样显示）

**原因**：知乎的 Markdown 解析对某些公式格式不兼容

**解决方法**：
1. 选中公式文字（包括 $ 符号）
2. 删除 $ 符号
3. 点击工具栏「公式」按钮 → 选择「行内」或「块级」
4. 在弹出的公式编辑器里粘贴 LaTeX 代码
5. 点击确认

### Q2：表格显示错乱

**原因**：可能是粘贴时格式丢失

**解决方法**：
1. 删除错乱的表格
2. 重新从 md 文件中复制表格部分
3. 粘贴到一个空白行
4. 如果还是不行，用知乎编辑器自带的「插入表格」功能手动建表

### Q3：引用块不显示灰色背景

**解决方法**：
1. 选中引用的文字
2. 点击工具栏的「引用」按钮（引号图标）
3. 应该会变成灰色背景

### Q4：链接打不开

**检查**：
1. 链接是不是完整的（包含 https://）
2. 是不是多了空格或少了字符
3. 在浏览器新标签页里手动输入试试

### Q5：图片上传失败

**可能原因**：
- 网络问题 → 重试
- 图片太大 → 压一下再传
- 格式不支持 → 确保是 jpg/png
