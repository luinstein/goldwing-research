三、各平台内容策略

3.1　GitHub Pages（存档 · 官方完整版）

  • 内容：HTML 完整版报告（当前 v1.6），保留所有图表、动画、交互
  • 形式：GitHub 仓库 + GitHub Pages 部署
  • 仓库结构：
    • paper/ — 各版报告 HTML
    • data/ — 关键数据表
    • visualizations/ — 可视化页面
    • README.md — 项目介绍 + 快速链接
  • 作用：所有其他平台链向这里；Git 历史作为版本证明和时间戳

3.2　知乎专栏（主平台 · 深度）

  • 专栏名：素数星空 / 金翼计划
  • 形式：系列文章，拆分为 2-3 篇发布（而非一篇超长文），利于持续涨粉
  • 系列规划：
    1. 第一篇：漂移假象——为什么哥德巴赫计数的"超泊松"是假的（最有冲击力的发现，吸引点击）
    2. 第二篇：亚泊松涨落——素数对的分布比你想的更均匀（核心结果 + 窄窗口验证）
    3. 第三篇：七个开放问题——关于哥德巴赫猜想，数值实验告诉了我们什么（抛砖引玉，引发讨论）
  • 每篇结构：通俗开头 → 核心发现 → 图表 → 深入解释 → 结尾引导关注 + 链接完整版
  • 互动策略：认真回复每一条评论；有价值的问题可以更新到报告里

3.3　小红书（辅助 · 引流破圈）

  • 内容形式：6 张图 + 300 字文案
  • 图片规划：
    1. 封面：素数星空可视化截图 + 大字标题
    2. 核心发现：κ 对比图（假象 vs 真相）
    3. 漂移律：17 尺度收敛曲线图
    4. 窄窗口实验：模型无关验证示意图
    5. d(N) 分布或耦合刚性图
    6. 结尾：金翼计划 + "完整版见评论区"
  • 文案风格：科普 + 第一人称叙事，"我用计算机数了十亿个偶数..."
  • 标签：#数学 #素数 #哥德巴赫猜想 #数论 #科普 #编程 #计算机

3.4　V2EX（辅助 · 技术圈层）

  • 节点：分享创造
  • 标题：做了一个哥德巴赫猜想的数值研究，发现涨落是亚泊松的
  • 正文：3-5 段话讲清楚背景 + 核心发现 + 方法 + 链接
  • 策略：真诚分享，不要过度营销；回帖认真交流
